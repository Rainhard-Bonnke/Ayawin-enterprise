# Payroll Statutory Files

Status: exports are not enabled. The payroll remittance ledger currently supports PAYE, NSSF, SHA/SHIF, and Affordable Housing Levy liabilities and payments, but no filing file is generated by this ERP.

## Required Output Files

- KRA PAYE return (P10)
- NSSF employer contribution file
- SHA contribution file
- Affordable Housing Levy contribution file
- Annual P9 card PDF per employee

## Template Verification Gate

Reviewed on 2026-11-09. Public searches found KRA PAYE filing guidance, but did not expose a current downloadable P10 upload schema. NSSF, SHA employer collection, and Affordable Housing Levy searches likewise did not expose authoritative, current machine-upload layouts. The SHA employer payroll portal found in public search requires sign-in. No file generator should be implemented from guessed column names or third-party examples. Obtain the current templates or specifications from each agency/authorized employer portal before enabling export.

## Validator Requirements Before Export

- KRA PIN format must validate for every employee included in P10.
- National ID, NSSF number, and SHA member number must be present where required by the verified template.
- Employee counts and contribution totals must reconcile to posted payslips and the statutory remittance ledger for the same payroll run/period.
- Any error blocks the export and identifies the employee, field, and agency file.
- Record template source, retrieval date/version, payroll run, preparer, and export timestamp with each generated artifact.

No payroll has been filed by this document or by the ERP. Obtain agency templates before implementation proceeds.
